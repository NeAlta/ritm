# Ритм для iPhone и Android

Веб-приложение «Ритм»: Тело, Деньги, Питание, Цели и Семья с общими данными. Работает без интернета, данные хранятся только на телефоне.

**Установка на iPhone:** откройте сайт в Safari → «Поделиться» → «На экран Домой» → «Добавить».

**Установка на Android:** откройте сайт в Chrome → кнопка «Установить Ритм» или меню ⋮ → «Установить приложение».

Файлы собраны скриптом `make_pwa.py` из исходников Ритма; вручную их не правят.
