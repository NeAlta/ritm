# Ритм для iPhone

Веб-приложение «Ритм»: Тело, Деньги, Питание и Цели с общими данными. Работает без интернета, данные хранятся только на телефоне.

**Установка:** откройте сайт в Safari на iPhone → «Поделиться» → «На экран Домой» → «Добавить».

Файлы собраны скриптом `make_pwa.py` из исходников Ритма; вручную их не правят.
